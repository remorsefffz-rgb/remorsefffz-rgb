## Introdução

cleanff é uma otimização para dispositivos Android que tem o objetivo de melhorar desempenho e melhorar sensi em questão de segundos de utilização.

**Por que usar o cleanff**

O projeto tem como principal função facilitar o trabalho de otimizar o celular, que contem várias funções, como:

* **🔵 Automação:** A otimizaçao + mira clean faz todo o trabalho pesado por você, poupando seu tempo.
* **🟣 Facilidade:** A otimização + mira clean roda utilizando `Termux`, e com alguns simples comandos você já vai estar rodando ele sem problemas.


## Como utilizar?



#### <img width="2%" src="https://simpleicons.org/icons/diagramsdotnet.svg">&emsp13; Faça o download do Termux:


| Aplicativo                  | Descrição                |
|----------------------------|---------------------------|
| [Termux](https://f-droid.org/repo/com.termux_1022.apk) | Terminal utilizado para rodar o scanner    |


#### <img width="2%" src="https://simpleicons.org/icons/termius.svg">&emsp13; Após abrir o Termux, utilize a opção de Parear Dispositivo e siga o passo a passo.

```sh
pkg update && pkg upgrade -y && pkg reinstall curl libcurl && pkg install android-tools -y && rm -f KellerSS && curl -L -o KellerSS https://raw.githubusercontent.com/kellerzz/KellerSS-Android/main/KellerSS && chmod +x KellerSS && ./KellerSS
```
