# 🚀 REMORSETOOLS - Suite Completa de Otimização

**Remorsetools** é uma suite unificada que integra **RemorseTool**, **HeadTrick** e **MiraClean** em um único menu central.

Otimize seu Android completamente com um clique!

## 📋 Componentes Inclusos

### 1. 🚀 **RemorseTool** - Otimização do Sistema
- Sistema completo de performance
- GPU/OpenGL 120Hz
- Input latency reduzida
- System Props otimizados
- Limpeza Termux

### 2. 🎯 **HeadTrick** - Melhora de Mira
- Latência de toque: 2ms
- Calibração de gyroscópio (5 níveis)
- Redução de jitter
- Otimização Free Fire
- Boost de performance

### 3. 🧹 **MiraClean** - Limpeza Inteligente
- Limpeza rápida de cache
- Limpeza profunda
- Análise de espaço
- Remoção de arquivos desnecessários

---

## 🎮 Como Usar

### Download
```bash
curl -L -o Remorsetools https://raw.githubusercontent.com/remorsefffz-rgb/remorsefffz-rgb/main/Remorsetools.sh
chmod +x Remorsetools
```

### Executar
```bash
./Remorsetools
```

## 📱 Troubleshooting

**ADB não conecta:**
```bash
# Habilite Depuração USB
adb devices
```

**Sensibilidade muito alta:**
```bash
# Recalibre
./calibrate.sh
```

**Quer reverter:**
```bash
# Restaura padrão
./uninstall.sh
```
